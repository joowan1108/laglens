# AI Usage Disclosure (running log)

This project was produced with substantial help from a generative AI coding assistant,
**Claude Code (Anthropic, model Claude Opus 5.5)**, directed by the student through a written goal specification
(`GOAL_PROMPT.md`, `GOAL_SHORT.txt`). The student chose the topic among AI-proposed candidates, reviewed the
outputs, and is responsible for the submitted work. Nothing below was written by other people; external code,
data and images are listed in `docs/references.md`.
